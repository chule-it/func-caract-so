— Parte 01

Funciones que nunca se detienen

Seis tareas que el sistema operativo ejecuta todo el tiempo que el equipo está encendido.

01

Gestión de procesos

Decide qué tarea usa el procesador y en qué momento, para que varios programas corran "al mismo tiempo".

02

Gestión de memoria

Reparte y libera espacio en RAM entre los programas abiertos, evitando que se saturen entre sí.

03

Gestión de archivos

Organiza carpetas, permisos y ubicación de cada archivo dentro del almacenamiento.

recursos compartidos entre procesos
entrada de datos
04

Gestión de dispositivos

Traduce las señales del teclado, mouse, pantalla e impresora hacia el sistema y viceversa.

05

Seguridad y accesos

Controla usuarios, contraseñas y permisos para proteger la información del equipo.

06

Interfaz de usuario

Es el puente visual (ventanas, íconos) o de texto (comandos) entre la persona y la máquina.

— Parte 02

Características que lo definen

Cualidades esperables en cualquier sistema operativo bien construido.

Multitarea

Corre varios programas a la vez sin detenerlos entre sí.

Multiusuario

Varias cuentas usan el mismo equipo con espacios separados.

Portabilidad

Se adapta a distintas arquitecturas de hardware.

Confiabilidad

Se recupera ante errores sin perder datos.

Escalabilidad

Aprovecha mejor hardware conforme el equipo crece.

Interfaz accesible

Ofrece modo gráfico o de comandos según se necesite.
